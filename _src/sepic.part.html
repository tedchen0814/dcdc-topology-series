SEPIC 單端初級電感轉換器 04 SEPIC 升降壓轉換器 Single-Ended Primary-Inductor Converter · How it works DC → DC · UP / DOWN

SEPIC 用一顆低側開關（通常直接用升壓 IC）、兩顆電感 L1、L2 和耦合電容 CDC 組成，輸出可以高於、低於或等於輸入，而且輸入與輸出被 CDC 隔開。Q 導通時 L1、L2 同時經 Q 接地儲能，所以 開關電流 = iL1 + iL2 ≈ 輸入電流 + 輸出電流，比 BOOST 多了一整份 IOUT。 A SEPIC uses one low-side switch (usually a boost IC), two inductors and a coupling capacitor CDC. The output can be above, below or equal to the input, and CDC blocks DC between them. With Q on, both inductors charge through Q, so the switch carries iL1 + iL2 ≈ IIN + IOUT — a full IOUT more than a boost.

Q 導通（tON = D·T）

Q 導通，SW 節點為 0。有兩個回路同時經過 Q：CIN → L1 → Q → GND，VIN 對 L1 充電；CDC → Q → GND → L2，CDC（電壓約 VIN）對 L2 充電。兩顆電感電壓都約為 VIN，電流一起上升，所以 iQ = iL1 + iL2。D 反偏、iD = 0，負載由 COUT 供電。

Two loops share Q: CIN → L1 → Q → GND charges L1 from VIN, and CDC → Q → GND → L2 charges L2 from CDC (≈ VIN). Both currents ramp up, so iQ = iL1 + iL2. D is reverse-biased and COUT feeds the load.

Q 關斷（tOFF = (1−D)·T）

兩顆電感電壓反向。回路一 CIN → L1 → CDC → D → COUT／負載：輸入經 L1 向負載供電，同時把 CDC 充回去；回路二 L2 → D → COUT／負載。兩股電流在 D 匯合，iD = iL1 + iL2、iQ = 0。Q 此時承受 VIN + VOUT + VF。

Both inductor voltages reverse. CIN → L1 → CDC → D → load feeds the output and recharges CDC; L2 → D → load adds the second current. They merge in D, so iD = iL1 + iL2 and iQ = 0. Q now blocks VIN + VOUT + VF.

DCM 空檔（iD = 0）

負載很輕時，iL1 + iL2 在週期結束前降到 0，D 截止。這時 iL1 與 iL2 不一定各自為 0，而是大小相等、方向相反，沿 L1 → CDC → L2 → GND 環流並維持定值；SW 節點回到約 VIN。

At light load the sum iL1 + iL2 reaches zero and D turns off. The two inductor currents need not be zero individually: they stay equal and opposite, circulating through L1, CDC and L2. SW settles near VIN.

SEPIC 的 L1 串在輸入側，所以 L1 平均電流 = IIN；CDC 不能通過直流，L2 的平均電流只能從二極體流出，所以 L2 平均電流 = IOUT。Q 導通時兩顆電感電流一起流過 Q，開關峰值 = IL1(peak) + IL2(peak)。跟 BOOST 比，同一顆 IC 的限流值要同時扛輸入和輸出電流，所以 SEPIC 能輸出的電流明顯較少。 L1 is in series with the input, so its average is IIN. CDC blocks DC, so L2's average must leave through the diode: IL2 = IOUT. Both flow through Q while it is on, so the switch peak is IL1(peak) + IL2(peak). Compared with a boost, the same switch limit has to cover input and output current together.

原文推導（XL6019 SEPIC，忽略效率）
(IL1 + IL2)·(1 − D) = IO … (1)　IL1·(1 − D) = IL2·D … (2)　→ IL2 = IO　→ IL1 = IIN = D/(1 − D)·IO = (VO/VIN)·IO　→ IQ1(peak) = 1.2·(IL1 + IL2) = 1.2·(1 + VO/VIN)·IO
The note's derivation: diode current balance (1) and CDC charge balance (2) give IL2 = IO and IL1 = IIN = (VO/VIN)·IO. With 20% ripple, the switch peak is 1.2·(1 + VO/VIN)·IO, and the IC's switch current rating must exceed it with margin.

PCB Layout 佈局

  • Hot loop：Q → CDC → D → COUT原文圖示補充
    原文圖 1 標出的開關電流回路包含 Q、CDC、D 與 COUT，比 BOOST 多了一顆 CDC。四顆元件要擠在一起，輸出端高頻 MLCC 緊貼 D 陰極與 Q 的地（PGND）。 The note's hot loop runs through Q, CDC, D and COUT — one part more than a boost. Keep all four tight.
  • 輸入電流連續，EMI 較低原文補充
    原文指出 SEPIC 有低 EMI 輻射的特點：L1 在輸入側，輸入電流是連續的三角波，CIN 壓力小。輸出側 iD 是 IIN + IOUT 大小的脈衝，COUT 承受大部分漣波電流。 Input current is continuous (low EMI, as the note says); the output sees pulses of IIN + IOUT.
  • 兩個切換節點補充
    SW（0 ↔ VIN + VOUT）和 CDC 右側節點（−VIN ↔ VOUT）都是高 dv/dt 節點，銅箔夠承載電流即可，FB 走線與分壓電阻遠離這兩處與兩顆電感。 Both SW and the CDC–L2 node swing hard; keep their copper small and FB routing away.
  • 兩顆分立電感可分開擺原文補充
    原文提到可使用兩個獨立的分立功率電感，擺放較有彈性，但兩顆電感的地端與 Q 的地都要短而寬地回到 CIN／COUT 的地。 Two discrete inductors can be placed freely, but return both to a solid power ground.

選料 Component selection

  • 開關管耐壓 > VIN + VOUT原文
    Q 關斷時承受 VIN + VOUT（再加 VF 與振鈴突波）。所以升壓 IC 的 SW 腳耐壓要大於最高輸入與輸出電壓之和，而不是只看 VOUT。 The switch blocks VIN + VOUT, so the IC's SW rating must exceed the sum, not just VOUT.
  • 蕭特基耐壓 > (VIN + VOUT) 且留 30% 餘量原文
    D 在 Q 導通時承受 VIN + VOUT 的反向電壓，原文建議再留 30% 餘量。原文電路用 B560C（5 A／60 V）。二極體平均電流 = IOUT，峰值 = IL1(peak) + IL2(peak)補充。 The diode's reverse voltage is VIN + VOUT; the note asks for 30% headroom and uses a B560C. Its peak equals the switch peak.
  • 耦合電感注意同名端原文補充
    若 L1、L2 用耦合電感（同一磁芯），要注意同名端方向；用分立電感則不用。耦合比 1:1 時，所需電感量約為分立時的一半。 With a coupled inductor, watch the dot polarity; discrete parts don't care. A 1:1 coupled part needs about half the inductance.
  • 耦合電容 CDC原文補充
    CDC 平均電壓約等於 VIN，耐壓要高於 VIN(max)；它要承受 ≈ IOUT·√(VOUT/VIN) 的 RMS 電流，選低 ESR、漣波電流額定足夠的電容。原文電路用 100 µF／63 V。 CDC sits at about VIN and carries ≈ IOUT·√(VOUT/VIN) RMS; pick low ESR and adequate ripple rating. The note uses 100 µF / 63 V.
  • 電感電流額定原文
    L1 平均 = IIN、L2 平均 = IOUT，原文以 20% 漣波估峰值 IL(peak) = 1.2·IL。原文電路 L1、L2 都用 47 µH／4 A。 L1 averages IIN, L2 averages IOUT; the note takes the peak as 1.2× average and uses 47 µH / 4 A parts.

設計提醒 Design reminders

  • 選 IC 看開關電流：> 1.2·(1 + VOUT/VIN)·IOUT原文
    晶片的額定開關電流一定要大於 IQ1(peak)，並留有餘量。VIN 最低時 VOUT/VIN 最大，開關電流也最大，要用 VIN(min) 來算。 The IC's switch current rating must exceed 1.2·(1 + VO/VIN)·IO with margin; evaluate at VIN(min).
  • 同一顆 IC 做 SEPIC，功率約為 BOOST 的一半原文
    原文指出 SEPIC 效率比 BOOST 或 BUCK 低約 8 個百分點，使用相同晶片時輸出功率只有 BOOST 的一半左右。可以用上方「輸出電流上限」和 BOOST 頁對照。 The note says efficiency is about 8 points lower than boost or buck, and the same chip delivers roughly half the boost output power.
  • 輸入與輸出隔直流原文補充
    CDC 隔開輸入與輸出，不像 BOOST 有 VIN → L → D 的直通路徑，所以關機時輸出可以真正放電到 0，輸出短路時也較容易保護。 CDC blocks DC, so there is no VIN → L → D path as in a boost: the output can discharge to 0 at shutdown and shorts are easier to handle.
  • 迴路補償較難補充
    SEPIC 是四階系統，除了類似 BOOST 的右半平面零點，CDC 與 L2（及 L1）還會形成諧振，讓相位急劇下降。迴路頻寬通常要壓在諧振頻率以下，CDC 可加大或加阻尼。 A SEPIC is fourth-order: besides an RHP zero, CDC resonates with the inductors. Keep crossover below that resonance.
  • 佔空比與 VIN 範圍補充
    D = VOUT/(VIN·η + VOUT)：VIN = VOUT 時約 50%，VIN 越低 D 越大。確認 VIN(min) 時 D 不超過晶片最大佔空比。 D is about 50% at VIN = VOUT and rises as VIN drops; check it against the IC's maximum duty at VIN(min).
